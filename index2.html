Git Reset Learning

There are two types of git reset: git reset --soft : This will move the HEAD to the specified commit, but it will not change the index or working directory. This means that the changes made in the commits after the specified commit will still be present in the working directory and can be staged again if needed. git reset --hard : This will move the HEAD to the specified commit and discard all changes made in the commits after the specified commit. This means that the changes made in the working directory and index will be lost, and the repository will be in the state of the specified commit. git reset --mixed : This will move the HEAD to the specified commit and reset the index to match the specified commit, but it will not change the working directory. This means that the changes made in the commits after the specified commit will still be present in the working directory, but they will not be staged for commit. git reset HEAD~1
